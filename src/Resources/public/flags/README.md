# Flag icons

4×3 SVG flags from [lipis/flag-icons](https://github.com/lipis/flag-icons) (`flags/4x3/`).

- Filenames match Shopware `translationCode` values (e.g. `de.svg`, `en-US.svg`, `cs.svg`)
- `en.svg` uses the GB flag artwork; `en-US.svg` is US

- Add a locale: copy the matching 4×3 SVG from upstream and name it `{translationCode}.svg`
